# 🏠 Telegram-бот «Домик в Шерегеше»

Бот-администратор в Telegram для аренды дома на курорте: меню с информацией о доме, ценах, расположении, удобствах, правилах и фото, а также связь с администратором через группу.

---

## Возможности

- **Inline-меню** с 9 разделами (о домике, цены, расположение, удобства, фото, правила, FAQ, контакты)
- **Фото в меню** — главное фото и отдельное фото дома по кнопке «📸 Фото» обновляется
- **Связь с администратором** — пользователь пишет вопрос, он уходит в группу админов, любой админ отвечает через Reply, ответ приходит пользователю
- **Кнопка «Назад в меню»** под каждым ответом
- **Обработка устаревших сообщений** — если сообщение старше 48 часов, бот подсказывает нажать `/start`
- **Секреты в `.env`** — токен и ID группы не попадают в репозиторий

## 🚀 Как развернуть проект

### Локальный запуск

1. **Клонируйте репозиторий**
```bash
git clone git@github.com:DariaBarashkina/gesh-bot.git
cd gesh-bot
```

2. **Создать и активировать виртуальное окружение**
* Для Linux/macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```

* Для Windows:
```bash
python -m venv venv
source venv/Scripts/activate
```

3. **Установить зависимости**
* Для Linux/macOS:
```bash
python3 -m pip install --upgrade pip
pip install -r backend/requirements.txt
```

* Для Windows:
```bash
python -m pip install --upgrade pip
pip install -r backend/requirements.txt
```

4. **Создать файл .env (в корне проекта) с переменными окружения**
```bash
touch .env
```
